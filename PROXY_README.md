# Ragnarok Online TCP Proxy

Асинхронный TCP прокси-сервер для Ragnarok Online, написанный на Rust с использованием tokio.

## Описание

Этот прокси служит промежуточным звеном между клиентом Ragnarok Online и сервером игры. Он перехватывает и пробрасывает весь трафик между клиентом и сервером, предоставляя возможность для анализа пакетов и будущей реализации автоматизации (бота).

## Функции

- ✅ Асинхронная обработка подключений с использованием tokio
- ✅ Двунаправленная передача данных между клиентом и сервером
- ✅ Логирование пакетов с отображением Packet ID
- ✅ Обработка множественных клиентских подключений
- ✅ Детальное логирование с помощью tracing
- ✅ Обработка ошибок с color-eyre

## Сборка

```bash
cargo build --release
```

## Запуск

### Простой запуск с настройками по умолчанию:
```bash
cargo run --bin proxy
```

### Запуск с пользовательскими настройками:
```bash
cargo run --bin proxy 127.0.0.1:6900 127.0.0.1:6121
```

Где:
- `127.0.0.1:6900` - адрес и порт для прослушивания клиентских подключений
- `127.0.0.1:6121` - адрес и порт сервера Ragnarok Online

## Настройка клиента

1. Запустите прокси-сервер
2. Настройте клиент Ragnarok Online для подключения к `127.0.0.1:6900` вместо оригинального сервера
3. Прокси автоматически перенаправит весь трафик на реальный сервер

## Логирование

Прокси логирует следующую информацию:
- Подключения/отключения клиентов
- Количество переданных байт
- Packet ID для анализа протокола RO
- Ошибки подключения и передачи данных

Для увеличения детализации логов установите переменную окружения:
```bash
RUST_LOG=debug cargo run --bin proxy
```

## Архитектура

```
Клиент RO <-> TCP Proxy <-> Сервер RO
              (127.0.0.1:6900)
```

### Основные модули:

- `TcpProxy` - основной сервер прокси
- `Connection` - обработка индивидуальных подключений
- `ProxyConfig` - конфигурация сервера
